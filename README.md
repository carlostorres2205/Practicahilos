# Práctica de Hilos en JavaFX

## Herramientas utilizadas

- Java 21
- JavaFX
- Maven
- IntelliJ IDEA
- Scene Builder

## ¿Qué hace el programa?

- Procesa 100 registros de clientes.
- Procesa 50 registros de productos.
- Ejecuta los dos procesos al mismo tiempo.
- Muestra el avance con barras de progreso.
- Permite detener cada proceso por separado.
- Permite reiniciar las barras.
- Evita ejecutar un mismo proceso dos veces.
